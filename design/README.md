# WSP color study

Five review-only homepage concepts. Run `node scripts/build.mjs` then `node design/color-study.mjs`; review at `/color-study/`. Captured comparison images are in the ignored review folder. The generator compresses hero spacing consistently across the five concepts to fit the same comparison viewport; production homepage spacing is unchanged.

Recommendation: Classic varsity (01), Carolina athletics blue #7BAFD4, navy #13294B, and white. Use navy for normal text on white and on Carolina blue, white on navy, and blue for buttons, bands, and selected large headings. Blue-on-navy / navy-on-blue contrast is 6.17:1. Keep paragraphs dark rather than making all typography light blue. For a near-black font preference, #151515 in option 03 is the strongest alternative.

The earlier color #4B9CD3 is UNC's web/digital blue. The athletics brand guide lists #7BAFD4. These are distinct documented applications; do not call one a universal exact UNC color. Option 04 keeps the web color and gives it more visual area.

Color relationship rationale: use related blues with neutrals for cohesion; change light/dark area and contrast to distinguish the options. No claim that a hue guarantees a particular psychological response or conversion result. Collegiate character also depends on athletic photography, consistent branding, and bold condensed type. Retain WSP's own mark.
